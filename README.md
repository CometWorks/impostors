# PR images

Comparison screenshots linked from the far view PRs. Not code: never merge this branch.

Made by `tests/compare.py` on Linux with a headless client at the medium preset, 1280x720.
Each row is a distance, each column pair a view direction from a cube corner: the real
object on the left, its impostor on the right.

- `grid-visitor-ion.jpg`: the Visitor Ion ship, 100 to 3200 m
- `asteroid512-ao-off.jpg`, `asteroid512-ao-on.jpg`: a 512 m asteroid, 800 to 12800 m,
  without and with `AsteroidOcclusion`
- `asteroid256-ao-off.jpg`, `asteroid256-ao-on.jpg`: a 256 m asteroid, 400 to 12800 m
